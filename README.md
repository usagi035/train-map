# 路線図エディタ

駅・踏切・路線を自由に配置して路線図を作れる、**ブラウザで動く Web アプリ**です。
インストーラーもサーバーも不要で、`index.html` を配信するだけで動作します。
駅の間隔や路線の色・太さ、背景色をGUIで調整でき、複数の路線図を同時に開いて編集できます。

## 主な機能

- **駅の配置**: クリックで駅を追加。線の上をクリックすると、駅と駅のあいだに挿入できます。追加モードのまま**既存の駅(本体でも駅名でも)をクリックすると、駅は追加されず、その駅を選択した状態で「選択・移動」モードに自動で切り替わります**(そのままドラッグすれば移動できます)
- **駅の間隔の調整**: ドラッグで動かすほか、「前の駅との間隔」に数値を入れて指定できます(1マス = グリッド1つ分)。駅と駅のあいだには間隔が表示されます
- **駅名の移動と回転**: 駅名テキストをドラッグで好きな位置に移動できます(クイック操作パネルの「グリッドに合わせる」がONのときはグリッドにスナップ)。文字の向きは 普通 / 斜め(45°) / 縦(90°) から選べます
- **乗り換え駅(ターミナルハブ)**: 「乗り換え駅を追加」で置いた乗り換え駅は、**どの路線にも属さない「路線外」の駅**として作られます(路線に依存しません)。**普通の駅を選択して左のクイック操作パネルの「乗り換え駅(ターミナルハブ)」のスイッチをONにすれば、後から乗り換え駅に変更できます**(OFFにすると通常の駅に戻ります)。同じくクイック操作パネルのチェックリストで路線にチェックすると組み込まれ、複数の路線に同じ駅を共有できます。チェックを全部外すと、再び路線外に戻ります。1つを動かす・名前を変えると、属しているすべての路線に反映されます。路線を削除しても、路線外の乗り換え駅は残ります
- **接続する駅の設定**: **普通の駅でも乗り換え駅でも**、**路線ごとに別の「接続する駅」リスト**を持たせられます(1号線用・2号線用…)。右パネルのセレクトで駅を選ぶと**その場でリストに追加**され、↑↓ボタンかドラッグ&ドロップで順番を入れ替えられます(ドラッグは同じリストの中だけで入れ替え。行をクリックすると、その駅を選択してパネルが切り替わります)。路線に属さないときは「路線外」という1つのリストになり、路線をチェックするとその路線のリストへ移ります。**登録した接続は、その駅から接続先の駅へ通常の路線と同じ線で描画されます**(色と太さは接続先の駅の路線、路線外の接続先はグレー)。接続先の駅を削除したときは、リストからも自動的に外れます
- **幹線道路**: 「幹線道路を引く」ツールで、クリックで頂点をつないで道路を引きます。`Enter`(またはダブルクリック、最初の頂点をクリック)で確定、`Esc`で中止、`Ctrl + Z`で頂点を1つ戻します。「選択・移動」に戻って道路をドラッグすると移動、頂点(□)をドラッグすると形を調整できます。路面の内側に白い車線が入って表示され、道路ごとに色と幅を変えられます
- **バス停 / バスターミナル**: 幹線道路とは**独立した要素**です。専用のツールボタンで、キャンバスのどこにでも置けます(道路がなくても大丈夫)。右パネルで 名称・種別(バス停 ⇔ バスターミナル)・色・名称の向きを変更できます。ドラッグで移動、`Delete` で削除します
- **踏切の配置**: 線の近くをクリックして配置。ドラッグすると線に沿って動きます
- **駅の形と色**: ○・◎(特急停車駅など)・□・◇から選べて、駅ごとに色も変えられます
- **ラベル枠**: ドラッグで任意の大きさの四角形を置き、文字(ラベル)と色を付けられます
- **画像のインポート**:  「画像を追加」で画像ファイル(PNG・JPG・GIF・WebP)を選ぶと、**画像要素**としてキャンバスに配置されます(位置は表示している画面の中央)。ドラッグで移動、右下の■をドラッグでリサイズ、右パネルで 不透明度・重ねる順(背面 / 前面)・画像の変更・削除を操作できます。**背面(下敷き)にすると道路や線路より下に描画される**ので、既存のマップや写真を下に敷いてなぞる作業ができます。背面の画像は**選択中以外すり抜け**になるので、下の要素の選択や□選択を邪魔しません(右パネルの「画像」一覧から選べます)。複数枚置け、`Delete`・□での一括削除・`元に戻す`・JSON書き出しにも対応。大きい画像は自動で縮小・圧縮して保存され、保存領域の上限に近づくと注意が表示されます
- **広がるキャンバス**: 端に近づくと自動でキャンバスが広がります(draw.ioのように必要分だけ拡張)。`Space + ドラッグ` または中ボタンドラッグで画面を移動できます
- **ズーム**: 拡大・縮小ができます(ボタン、または `Ctrl + マウスホイール`)
- **複数の路線**: 1つの路線図の中に、色や太さの違う路線を何本でも描けます
- **レイヤー(表示・重ね順・編集ロック)**: 右パネルの「路線(レイヤー)」で、**路線1本ずつをレイヤーとして管理**できます。👁で表示/非表示(路線を隠すと、その路線の駅・踏切も一緒に隠れます)、🔒で編集ロック(キャンバスでの選択・ドラッグ・削除・駅と踏切の追加を禁止。右パネルからの名前や色の変更は可能)、↑↓で重ね順(**リストの上にある路線ほど手前に描画**されます。並べ替えても線の形は変わりません)。左のクイック操作パネルの「その他の表示」で、幹線道路・バス停・ラベル枠・画像も種類ごとに表示/非表示できます(非表示の種類に要素を追加すると、自動で表示に戻ります)。表示/非表示や並べ替えは「元に戻す」でも戻せます
- **環状線(輪)**: 左のクイック操作パネルの「路線」で**「環状線(最後と最初をつなぐ)」のスイッチをONにすると、最後の駅と最初の駅がつながって輪になります**。路線リストには「環」の印が付きます。閉じた区間にも駅・踏切を置け、駅間隔の表示・踏切のドラッグ・左パネルの並べ替え・`Delete`による削除もすべて同じように使えます(OFFにすると開いた線に戻ります。踏切は元の位置に付いたまま新しい経路上に追随します)
- **駅の並べ替え(左パネル)**: 選択中の路線の駅が、線を引く順(経路)に左パネルへ一覧表示されます。行の ↑↓ ボタンかドラッグで並べ替えられます(並べ替えると線の形が変わります。踏切は位置を保ったまま追随)。行をクリックするとその駅を選択して、キャンバスの表示をその駅へ移します
- **複数の路線図**: タブで切り替えられます。別タブ(「別ウィンドウで開く」)で開いて、同時に編集することもできます
- **見た目の設定**: 路線ごとの色と線の太さ、路線図ごとの背景色
- **自動保存**: 編集内容はそのつど自動で保存されます
- **元に戻す / やり直す**: `Ctrl + Z` で操作を1つ戻し、`Ctrl + Y`(または `Ctrl + Shift + Z`) でやり直します。駅やバス停の追加・移動・削除、名前や色の変更、路線図の追加・削除などに対応しています(履歴は直近50件)。道路を引いている最中なら `Ctrl + Z` で最後に置いた頂点を1つずつ戻せます
- **□(矩形)での複数選択と一括削除**: 「選択・移動」モードで空白(または線)をドラッグして□で囲むと、中に収まった **駅・乗り換え駅・バス停・踏切・ラベル枠・幹線道路・画像** がまとめて選択されます(選んだ個数は右パネルに表示)。`Delete`(または「選択を削除」)でまとめて削除、`Esc` かクリックで解除できます。ドラッグせずにクリックしただけなら従来どおりの操作で、追加モード中にドラッグしても□選択にはなりません
- **書き出し / 読み込み**: 路線図をJSONファイルとして保存・復元できます
- **画像書き出し**: 現在の路線図をPNG画像として保存できます(ファイル名は路線図の名前)

## 使い方

### 起動後の流れ

1. 右パネルの「路線(レイヤー)」で、駅を置きたい路線を選びます
2. 上のツールバーで「駅を追加」を選び、キャンバスをクリックして駅を置きます
3. 「選択・移動」に戻して、駅をドラッグして位置を整えます。左パネルの ↑↓(またはドラッグ)で駅の並べ順=線の経路も変えられます
4. 「踏切を追加」を選び、線の近くをクリックして踏切を置きます
5. 乗り換え駅は「乗り換え駅を追加」で置きます。最初はどの路線にも属さないので、左のクイック操作パネルのチェックリストで属させたい路線にチェックします
6. バス路線図は「幹線道路を引く」で道路を引き、続いて「バス停を追加」「バスターミナルを追加」で停留所を置きます(バス停は道路とは独立した要素なので、道路がなくても置けます)

### ツールバー

| ボタン | できること |
| --- | --- |
| 選択・移動 | 駅・バス停・道路・ラベル枠・画像などをクリックして選択、ドラッグして移動。空白(または線)をドラッグして□で囲むと複数をまとめて選択できる |
| 駅を追加 | クリックした場所に駅を追加(選択中の路線に追加され、線の上なら駅と駅のあいだに挿入)。既存の駅をクリックしたら追加せず、その駅を選択して「選択・移動」へ自動で切り替わる |
| 乗り換え駅を追加 | 複数の路線に共有される乗り換え駅を追加 |
| 踏切を追加 | 線の近くをクリックして踏切を追加 |
| バス停を追加 | 道路に依存しないバス停を、クリックした場所に配置 |
| バスターミナルを追加 | 道路に依存しないバスターミナルを、クリックした場所に配置 |
| 幹線道路を引く | クリックで頂点を追加して道路を引く。`Enter` またはダブルクリック・最初の頂点のクリックで確定、`Esc` で中止、`Ctrl + Z` で頂点を1つ戻す |
| ラベル枠を追加 | ドラッグで四角形を追加(クリックだけなら標準サイズ) |
| 画像を追加 | 画像ファイル(PNG・JPGなど)を選んでキャンバスに配置。ドラッグで移動、右下の■でリサイズ、右パネルで不透明度と重ねる順(下敷き / 前面)を変更 |
| － / ＋ / 等倍 | 縮小 / 拡大 / 100%に戻す |
| 選択を削除 | 選択中の駅・バス停・道路・踏切・ラベル枠・画像を削除。□で複数選択していればまとめて削除 |
| ↶ 元に戻す / ↷ やり直す | 操作を1つ戻す / やり直す(履歴がないあいだはボタンは押せません) |
| 書き出し / 読み込み | JSONファイルとして保存 / 復元 |
| 画像書き出し | PNG画像として保存 |

### 左パネル

左のサイドバーは、**上に「選択中の路線の駅リスト」、下に「クイック操作パネル」を1列に統合**しています。下のクイック操作は**下端から高さ固定**で並び、スクロールするのは上の駅リストだけです(画面が低いときはクイック操作が最大75%まで縮み、そのときだけ中身がスクロールします)。

- **選択中の路線の駅**: 選んでいる路線の駅を、線を引く順(経路)に上から並べて表示します。行の ↑↓ ボタン、または行をドラッグして並べ替えると、線の形(経路)が変わります。踏切は位置を保ったまま新しい経路上に追随します。行をクリックするとその駅を選択して、キャンバスの表示がその駅へ移ります。乗り換え駅には「乗」バッジ、行の先頭には駅の形と色が付きます

### サイドバーの幅

左右のサイドバーとキャンバスの間にある**縦のハンドル(目盛り)**をドラッグすると、そのサイドバーの幅を変えられます。幅はブラウザに記憶され、次に開いたときも同じ幅です。

- 既定の幅は **左 400px / 右 270px**。変更できる範囲は 左 260〜640px / 右 220〜560px で、**キャンバスは常に 200px 以上**確保されます(画面が狭いときは自動で両サイドが縮みます。このときは見たままの幅が表示され、記憶した値は変わりません)
- ハンドルを**ダブルクリック**すると既定値に戻ります
- ハンドルをキーボードで選択してから **`←` / `→`** で10px(`Shift` 付きで1px)、**`Home` / `End`** で最小/最大、**`Enter`** で既定値

### クイック操作パネル

左サイドバーの**下側**(駅リストの下)に、**開閉せずに常設のクイック操作パネル**があります。よく使うON/OFFのスイッチ(トグルスイッチ)と「路線を追加」を、右パネルを開くことなく操作できます。横幅は左サイドバーの幅に従います。

| グループ | 内容 |
| --- | --- |
| **路線** | **「グリッドに合わせる」**と**「追加後に選択へ戻る」**のスイッチ(上から2つ)、「路線を追加」ボタン、選択中の路線の「環状線(最後と最初をつなぐ)」スイッチ |
| **ターミナル(乗り換え駅)** | 選択中の駅の「乗り換え駅(ターミナルハブ)」スイッチと、属する路線のチェックリスト(駅が選択されているときだけ表示されます) |
| **その他の表示** | 幹線道路 / バス停 / ラベル枠 / 画像 の表示スイッチ |

この3つは元来右パネルにあった項目で、左へ移動しています(右パネル側には表示されません)。路線(レイヤー)一覧や、選択中の路線の名前・色・太さ・削除は右パネルに残っています。

「グリッドに合わせる」「追加後に選択へ戻る」は元来ツールバーにあったチェックボックスで、ここ(「路線」グループの先頭)へ移動しました。**設定は画面を開いている間だけ有効で、JSON・localStorage には保存されません**(次に開くとONに戻ります)。

### 右パネル

右パネルは**開閉できる6つのグループ**に整理されています。**見出しをクリックすると開閉**し、開閉状態は記憶されます。見出しの右側には件数(路線・道路・画像の枚数)や、選択中の路線名が表示されます。

| グループ | 内容 |
| --- | --- |
| **選択中:◯◯** | 選んだ要素の設定(下の一覧)。選択していないときは表示されません。要素を選ぶと自動的に開きます |
| **路線(レイヤー)** | 路線の切り替えと、路線ごとの 👁 表示/非表示・🔒 編集ロック・↑↓ 重ね順(「路線を追加」と「その他の表示」の4つの表示スイッチはクイック操作パネル) |
| **選択中の路線** | 名前、色、線の太さ、「この路線を削除」(「環状線(最後と最初をつなぐ)」のON/OFFはクイック操作パネル) |
| **幹線道路** | 引いた道路の一覧(クリックで選択)と「幹線道路を引く」ボタン |
| **画像** | インポートした画像の一覧(サムネイル・クリックで選択)と「画像を追加」ボタン |
| **路線図の設定** | 路線図の名前・背景色、「別ウィンドウで開く」「この路線図を削除」(既定は閉じた状態) |

**ON/OFFを1つで切り替える項目**は、**トグルスイッチ**(左に文言、右にスイッチ。ON=緑、OFF=グレー)です(「その他の表示」の4つ、「環状線(最後と最初をつなぐ)」「乗り換え駅(ターミナルハブ)」、「グリッドに合わせる」「追加後に選択へ戻る」)。これらはすべて左のクイック操作パネルに並んでいます。中身はチェックボックスなので、ON/OFFの判定・キーボード操作(Tab で移動して Space で切替)も同じ仕組みで動きます。複数から選べる「属する路線」のリストだけが、見たままのチェックボックスです。

**「選択中」グループの中身**

- **選択中の駅 / 乗り換え駅**: 駅名・形・色の変更、駅名の向き(普通 / 斜め / 縦)。「乗り換え駅(ターミナルハブ)」のスイッチと属する路線のチェックリストは**左のクイック操作パネル**に表示されます。**まだ乗り換え駅でない普通の駅は、スイッチをONにすれば後から乗り換え駅に変更できます**(OFFにすると元に戻ります)。チェックを全部外すと「路線外」と表示され、どの路線にも属さない乗り換え駅になります。属している路線では、前の駅との間隔(マス)も指定でき、間隔を変えるとそれ以降の駅も一緒に動きます
- **接続する駅(普通の駅・乗り換え駅)**: 属している路線ごとに1つのリストが並びます(路線に属さないときは「路線外」のリスト)。セレクトで駅を選ぶと**その場で登録**されます(「追加」ボタンは不要)。行の ↑↓ ボタン、または行をドラッグして並べ替え、✕で外します。**行をクリックすると、その駅を選択してパネル(と左パネル・路線)が切り替わります**。セレクトはその路線の駅を先頭のグループにまとめ、行のラベルには必要に応じ路線名を併記します(路線名が重複していても区別できます)。色のバーはその駅が属する路線の色です(路線外の駅はグレー)。**登録した接続はキャンバスにも、通常の路線と同じ線で描画されます**(色と太さは接続先の駅の路線)
- **選択中のバス停 / バスターミナル**: 名称・種別(バス停 ⇔ バスターミナル)・色・名称の向き(普通 / 斜め / 縦)の変更。幹線道路とは独立した要素なので、共有用のチェックリストはありません
- **選択中の幹線道路**: 名前・色・幅の変更、「この道路を削除」。道路全体をドラッグで移動、頂点(□)をドラッグで形を調整できます
- **選択中の踏切**: 名前の変更
- **選択中のラベル枠**: ラベル、色、幅・高さ(マス)の変更。四角の右下の■をドラッグしても大きさを変えられます
- **選択中の画像**: 不透明度、重ねる順(背面=下敷き / 前面)、「画像を変更」(ファイルから差し替え)と「削除」。ドラッグで移動、右下の■をドラッグで大きさを変えられます。背面の画像は、選択しているときだけ当たり判定が有効になります
- **□で複数選択中**: 「選択・移動」で空白(または線)をドラッグして□を引くと、中に収まった要素がまとめて選択され、ここに個数が表示されます。`Delete` または「選択を削除」で一括削除、`Esc` かクリックで解除

### タブと路線図の管理

- 上のタブで路線図を切り替えます。「＋」で新しい路線図を作ります
- タブの「✕」または `Alt + W` で、路線図を閉じます。**閉じてもデータは消えません**
- 開いている路線図があるあいだは、`Alt + W` でブラウザのタブは閉じません。すべて閉じると路線図の一覧画面になり、ブラウザのタブはいつでも手動で閉じられます
- 「一覧」ボタンから、閉じた路線図を開き直せます。データを消したいときは、一覧画面の「削除」か、右パネルの「この路線図を削除」を使います

### キーボードショートカット

| キー | 動作 |
| --- | --- |
| `Delete` / `Backspace` | 選択中の駅・バス停・道路・踏切・ラベル枠・画像を削除(□で複数選択していればまとめて削除) |
| `Ctrl + Z` | 元に戻す(道路の描画中は最後に置いた頂点を戻す) |
| `Ctrl + Y` / `Ctrl + Shift + Z` | やり直す |
| `Enter` / ダブルクリック | 描画中の幹線道路を確定 |
| `Esc` | 描画中の道路を中止(置いた頂点は残りません)。□の複数選択も解除し、それ以外は「選択・移動」ツールに戻る |
| `Space` + ドラッグ | キャンバスを掴んで画面移動(中ボタンドラッグでも可) |
| `Alt + W` | 表示中の路線図を閉じる(タブの「✕」と同じ) |
| `←` / `→` | サイドバーの幅変更ハンドルにフォーカスがあるとき、そのサイドバーの幅を10px変える(`Shift` 付きは1px) |
| `Home` / `End` / `Enter` | 同ハンドルで 幅の最小 / 最大 / 既定値へ(マウスのダブルクリックでも既定値) |

`Ctrl + W` はブラウザが「タブを閉じる」操作として先に受け取るため、アプリ側では取得できません。そこで Web 版では `Alt + W` を使っています。

テキスト欄(駅名など)にカーソルがあるあいだの `Ctrl + Z` は、入力中の文字に対するブラウザ標準の取り消しが使われます。キャンバスやボタンを選択した状態なら、路線図の操作を取り消します。

## 開発用の起動方法

[Node.js](https://nodejs.org/) が必要です。**依存パッケージはありません**(`npm install` は不要です)。

```bash
npm start
```

起動したらブラウザで <http://localhost:8080/> を開きます(`PORT=9000 npm start` でポートを変更できます)。

テストも依存パッケージなしで実行できます(Node 標準の `node --test`)。

```bash
npm test
```

`scripts/serve.cjs` は Node 標準モジュールだけで動く小さな静的サーバーで、リポジトリ直下をそのまま配信します。使いたいサーバーがあれば、リポジトリ直下を配信するものをどのみちでも構いません。

## Web版としての公開

ビルド工程はありません。**リポジトリ直下の `index.html` が入口**になっているので、GitHub Pages / Cloudflare Pages / Netlify 等の静的ホスティングにこのリポジトリをそのまま接続するだけで公開できます。

- 公開ディレクトリは**リポジトリ直下**を指定してください(JavaScript は ES Modules で読み込まれます)
- 「ファイルをダブルクリックして開く(`file://`)」は、ES Modules の読み込みがブロックされるブラウザ(Chrome など)では動きません。ローカルでは `npm start`、公開先は HTTPS を使ってください
- URL(ホスト名やポート)が変わると、それは別の保存領域として扱われます。開発中と公開先ではデータは共有されません

## データの保存場所とバックアップ

編集内容は、**ブラウザの保存データ(localStorage)**に自動保存されます。保存先は「どのサイト(プロトコル+ホスト名+ポート)で開いたか」単位なので、同じブラウザで同じURLを開けば同じデータが、URLが変われば別のデータが見えます。ブラウザの「サイトのデータを削除」をすると消えるため、PCの入れ替えやデータ削除に備えて、大切な路線図は「書き出し」でJSONファイルとして保存しておくことをおすすめします。

保存キーには `train-map:v1:` という名前空間を付けています(「路線図本体」「開いているタブ」など4つ)。同じサイトには別の公開物も置けるので、短い汎用的なキー名は使いません。以前の `railmaps` などの形式で保存していたデータは、**起動時に自動で新しいキーへ移され、元のキーもそのまま残ります**(移行でデータが消えることはありません)。

同じページを複数のタブで開いているときは、変更が自動で行き来します。ただし**入力中・ドラッグ中など、まだ確定していない編集があるタブでは上書きしません**。代わりに画面上部へ「別のタブでこの路線図が変更されました」という案内が出て、「相手の版を読み込む」「自分の版を残す」を選べます。どちらも選ばないうちは、そのまま勝手に画面が入れ替わることはありません。案内は画面を止めない表示なので、作業を妨げません。

「読み込み」で取り込んだJSONは、開く前に中身を確かめています。色は `#1a2b3c` の形以外、数値は数値以外(文字列など)、IDは英数字と `-` `_` 以外を**既定の値へ直して**から表示します。不正な値が混ざったファイルでも、画面が崩れたり操作できなくなったりすることを防ぎます。直した内容はコンソールに警告として出ます(本来のデータを捨てないために、まず「直して通す」方針です)。さらに**表示する直前にもう一度値の形を確かめます**(色・数値・IDごとに別の確認を通す)ので、取り込みの見落としがあっても属性へ不審な文字列が入り込むことはありません。

ページ自体には **Content Security Policy(CSP)** をかけています(`index.html` の meta)。**JavaScript は同じサイトのファイルからのみ実行可能**で、インラインの `<script>`・インラインのイベントハンドラ(`onclick` など)・`javascript:` URL はすべて拒否されます。外部サイトへの接続はすべて止め(`default-src 'none'`)、画像も同じサイトか `data:` URL のみ許可です。読み込み側の検証と表示直前の値の確認に加えて、このCSPでも守っています。

## 現在の制限

- 路線の分岐や、直線以外(曲線)の表現には対応していません(幹線道路も折れ線のみです)
- キャンバスは自動で広がりますが、原点は左上固定で右・下方向にのみ拡張されます
- 旧データ(道路を路線として保存していた形式)は、自動的に「独立した道路 + バス停」へ変換されます
- 同じ路線図を複数のタブ(またはウィンドウ)で同時に編集すると、あとから操作した側の変更が残ります
- CSS(見た目)のインライン指定は、画面の作り方上あちこちで使っているため **CSP の `style-src 'unsafe-inline'` で今も許可しています**。JavaScript 側はインラインを止めていますが、スタイル側は緩和点として残っています
- CSP は `<meta>` で効かせているため、`frame-ancestors` や `report-uri` など **HTTPヘッダでしか使えない指定は使えません**(現状は不要)
