# 路線図エディタ

駅・踏切・路線を自由に配置して路線図を作れる、Electron製のデスクトップアプリです。
駅の間隔や路線の色・太さ、背景色をGUIで調整でき、複数の路線図を同時に開いて編集できます。

## 主な機能

- **駅の配置**: クリックで駅を追加。線の上をクリックすると、駅と駅のあいだに挿入できます。追加モードのまま**既存の駅(本体でも駅名でも)をクリックすると、駅は追加されず、その駅を選択した状態で「選択・移動」モードに自動で切り替わります**(そのままドラッグすれば移動できます)
- **駅の間隔の調整**: ドラッグで動かすほか、「前の駅との間隔」に数値を入れて指定できます(1マス = グリッド1つ分)。駅と駅のあいだには間隔が表示されます
- **駅名の移動と回転**: 駅名テキストをドラッグで好きな位置に移動できます(「グリッドに合わせる」がオンのときはグリッドにスナップ)。文字の向きは 普通 / 斜め(45°) / 縦(90°) から選べます
- **乗り換え駅(ターミナルハブ)**: 「乗り換え駅を追加」で置いた乗り換え駅は、**どの路線にも属さない「路線外」の駅**として作られます(路線に依存しません)。右パネルのチェックリストで路線にチェックすると組み込まれ、複数の路線に同じ駅を共有できます。チェックを全部外すと、再び路線外に戻ります。1つを動かす・名前を変えると、属しているすべての路線に反映されます。路線を削除しても、路線外の乗り換え駅は残ります
- **接続する駅の設定**: 乗り換え駅には **路線ごとに別の「接続する駅」リスト**を持たせられます(1号線用・2号線用…)。右パネルのセレクトから追加し、↑↓ボタンかドラッグ&ドロップで順番を入れ替えられます(ドラッグは同じリストの中だけで入れ替え)。路線に属さない乗り換え駅(路線外)は「路線外」という1つのリストになり、路線をチェックするとその路線のリストへ移ります。**登録した接続は、乗り換え駅から接続先の駅へ通常の路線と同じ線で描画されます**(色と太さは接続先の駅の路線、路線外の接続先はグレー)。接続先の駅を削除したときは、リストからも自動的に外れます
- **幹線道路**: 「幹線道路を引く」ツールで、クリックで頂点をつないで道路を引きます。`Enter`(またはダブルクリック、最初の頂点をクリック)で確定、`Esc`で中止、`Ctrl + Z`で頂点を1つ戻します。「選択・移動」に戻って道路をドラッグすると移動、頂点(□)をドラッグすると形を調整できます。路面の内側に白い車線が入って表示され、道路ごとに色と幅を変えられます
- **バス停 / バスターミナル**: 幹線道路とは**独立した要素**です。専用のツールボタンで、キャンバスのどこにでも置けます(道路がなくても大丈夫)。右パネルで 名称・種別(バス停 ⇔ バスターミナル)・色・名称の向きを変更できます。ドラッグで移動、`Delete` で削除します
- **踏切の配置**: 線の近くをクリックして配置。ドラッグすると線に沿って動きます
- **駅の形と色**: ○・◎(特急停車駅など)・□・◇から選べて、駅ごとに色も変えられます
- **ラベル枠**: ドラッグで任意の大きさの四角形を置き、文字(ラベル)と色を付けられます
- **広がるキャンバス**: 端に近づくと自動でキャンバスが広がります(draw.ioのように必要分だけ拡張)。`Space + ドラッグ` または中ボタンドラッグで画面を移動できます
- **ズーム**: 拡大・縮小ができます(ボタン、または `Ctrl + マウスホイール`)
- **複数の路線**: 1つの路線図の中に、色や太さの違う路線を何本でも描けます
- **駅の並べ替え(左パネル)**: 選択中の路線の駅が、線を引く順(経路)に左パネルへ一覧表示されます。行の ↑↓ ボタンかドラッグで並べ替えられます(並べ替えると線の形が変わります。踏切は位置を保ったまま追随)。行をクリックするとその駅を選択して、キャンバスの表示をその駅へ移します
- **複数の路線図**: タブで切り替えられます。別ウィンドウで開いて、同時に編集することもできます
- **見た目の設定**: 路線ごとの色と線の太さ、路線図ごとの背景色
- **自動保存**: 編集内容はそのつど自動で保存されます
- **元に戻す / やり直す**: `Ctrl + Z` で操作を1つ戻し、`Ctrl + Y`(または `Ctrl + Shift + Z`) でやり直します。駅やバス停の追加・移動・削除、名前や色の変更、路線図の追加・削除などに対応しています(履歴は直近50件)。道路を引いている最中なら `Ctrl + Z` で最後に置いた頂点を1つずつ戻せます
- **□(矩形)での複数選択と一括削除**: 「選択・移動」モードで空白(または線)をドラッグして□で囲むと、中に収まった **駅・乗り換え駅・バス停・踏切・ラベル枠・幹線道路** がまとめて選択されます(選んだ個数は右パネルに表示)。`Delete`(または「選択を削除」)でまとめて削除、`Esc` かクリックで解除できます。ドラッグせずにクリックしただけなら従来どおりの操作で、追加モード中にドラッグしても□選択にはなりません
- **書き出し / 読み込み**: 路線図をJSONファイルとして保存・復元できます
- **画像書き出し**: 現在の路線図をPNG画像として保存できます(ファイル名は路線図の名前)

## 使い方

### 起動後の流れ

1. 右パネルの「路線」で、駅を置きたい路線を選びます
2. 上のツールバーで「駅を追加」を選び、キャンバスをクリックして駅を置きます
3. 「選択・移動」に戻して、駅をドラッグして位置を整えます。左パネルの ↑↓(またはドラッグ)で駅の並べ順=線の経路も変えられます
4. 「踏切を追加」を選び、線の近くをクリックして踏切を置きます
5. 乗り換え駅は「乗り換え駅を追加」で置きます。最初はどの路線にも属さないので、右パネルのチェックリストで属させたい路線にチェックします
6. バス路線図は「幹線道路を引く」で道路を引き、続いて「バス停を追加」「バスターミナルを追加」で停留所を置きます(バス停は道路とは独立した要素なので、道路がなくても置けます)

### ツールバー

| ボタン | できること |
| --- | --- |
| 選択・移動 | 駅・バス停・道路・ラベル枠などをクリックして選択、ドラッグして移動。空白(または線)をドラッグして□で囲むと複数をまとめて選択できる |
| 駅を追加 | クリックした場所に駅を追加(選択中の路線に追加され、線の上なら駅と駅のあいだに挿入)。既存の駅をクリックしたら追加せず、その駅を選択して「選択・移動」へ自動で切り替わる |
| 乗り換え駅を追加 | 複数の路線に共有される乗り換え駅を追加 |
| 踏切を追加 | 線の近くをクリックして踏切を追加 |
| バス停を追加 | 道路に依存しないバス停を、クリックした場所に配置 |
| バスターミナルを追加 | 道路に依存しないバスターミナルを、クリックした場所に配置 |
| 幹線道路を引く | クリックで頂点を追加して道路を引く。`Enter` またはダブルクリック・最初の頂点のクリックで確定、`Esc` で中止、`Ctrl + Z` で頂点を1つ戻す |
| ラベル枠を追加 | ドラッグで四角形を追加(クリックだけなら標準サイズ) |
| グリッドに合わせる | オンにすると、駅・バス停・道路の頂点・踏切・ラベル枠・駅名がグリッドに吸着します |
| 追加後に選択へ戻る | オンにすると、駅などを1つ追加するたびに「選択・移動」へ戻ります |
| － / ＋ / 等倍 | 縮小 / 拡大 / 100%に戻す |
| 選択を削除 | 選択中の駅・バス停・道路・踏切・ラベル枠を削除。□で複数選択していればまとめて削除 |
| ↶ 元に戻す / ↷ やり直す | 操作を1つ戻す / やり直す(履歴がないあいだはボタンは押せません) |
| 書き出し / 読み込み | JSONファイルとして保存 / 復元 |
| 画像書き出し | PNG画像として保存 |

### 左パネル

- **選択中の路線の駅**: 選んでいる路線の駅を、線を引く順(経路)に上から並べて表示します。行の ↑↓ ボタン、または行をドラッグして並べ替えると、線の形(経路)が変わります。踏切は位置を保ったまま新しい経路上に追随します。行をクリックするとその駅を選択して、キャンバスの表示がその駅へ移ります。乗り換え駅には「乗」バッジ、行の先頭には駅の形と色が付きます

### 右パネル

- **選択中の駅 / 乗り換え駅**: 駅名・形・色の変更、駅名の向き(普通 / 斜め / 縦)、「乗り換え駅(ターミナルハブ)」のON/OFFと属する路線のチェックリスト。チェックを全部外すと「路線外」と表示され、どの路線にも属さない乗り換え駅になります。属している路線では、前の駅との間隔(マス)も指定でき、間隔を変えるとそれ以降の駅も一緒に動きます
- **接続する駅(乗り換え駅のみ)**: 属している路線ごとに1つのリストが並びます(路線に属さないときは「路線外」のリスト)。セレクトで駅を選び「追加」で登録。行の ↑↓ ボタン、または行をドラッグして並べ替え、✕で外します。セレクトはその路線の駅を先頭のグループにまとめ、行のラベルには必要に応じ路線名を併記します(路線名が重複していても区別できます)。色のバーはその駅が属する路線の色です(路線外の駅はグレー)。**登録した接続はキャンバスにも、通常の路線と同じ線で描画されます**(色と太さは接続先の駅の路線)
- **選択中のバス停 / バスターミナル**: 名称・種別(バス停 ⇔ バスターミナル)・色・名称の向き(普通 / 斜め / 縦)の変更。幹線道路とは独立した要素なので、共有用のチェックリストはありません
- **選択中の幹線道路**: 名前・色・幅の変更、「この道路を削除」。道路全体をドラッグで移動、頂点(□)をドラッグで形を調整できます
- **選択中の踏切**: 名前の変更
- **選択中のラベル枠**: ラベル、色、幅・高さ(マス)の変更。四角の右下の■をドラッグしても大きさを変えられます
- **□で複数選択中**: 「選択・移動」で空白(または線)をドラッグして□を引くと、中に収まった要素がまとめて選択され、ここに個数が表示されます。`Delete` または「選択を削除」で一括削除、`Esc` かクリックで解除
- **路線図の名前 / 背景色**: 路線図ごとの設定。「別ウィンドウで開く」「この路線図を削除」もここにあります
- **路線**: 路線の切り替えと「路線を追加」
- **選択中の路線**: 名前、色、線の太さの変更。「この路線を削除」もここにあります
- **幹線道路**: 引いた道路の一覧(クリックで選択)と「幹線道路を引く」ボタン

### タブと路線図の管理

- 上のタブで路線図を切り替えます。「＋」で新しい路線図を作ります
- タブの「✕」または `Ctrl + W`(Macは `Cmd + W`)で、路線図を閉じます。**閉じてもデータは消えません**
- 開いている路線図があるあいだは、`Ctrl + W` でアプリは終了しません。すべて閉じると路線図の一覧画面になり、この状態でもう一度 `Ctrl + W` を押すとウィンドウが閉じます
- 「一覧」ボタンから、閉じた路線図を開き直せます。データを消したいときは、一覧画面の「削除」か、右パネルの「この路線図を削除」を使います

### キーボードショートカット

| キー | 動作 |
| --- | --- |
| `Delete` / `Backspace` | 選択中の駅・バス停・道路・踏切・ラベル枠を削除(□で複数選択していればまとめて削除) |
| `Ctrl + Z` | 元に戻す(道路の描画中は最後に置いた頂点を戻す) |
| `Ctrl + Y` / `Ctrl + Shift + Z` | やり直す |
| `Enter` / ダブルクリック | 描画中の幹線道路を確定 |
| `Esc` | 描画中の道路を中止(置いた頂点は残りません)。□の複数選択も解除し、それ以外は「選択・移動」ツールに戻る |
| `Space` + ドラッグ | キャンバスを掴んで画面移動(中ボタンドラッグでも可) |
| `Ctrl + W` / `Cmd + W` | 表示中の路線図を閉じる |

テキスト欄(駅名など)にカーソルがあるあいだの `Ctrl + Z` は、入力中の文字に対するブラウザ標準の取り消しが使われます。キャンバスやボタンを選択した状態なら、路線図の操作を取り消します。

## 開発用の起動方法

[Node.js](https://nodejs.org/) が必要です。

```bash
npm install
npm start
```

## .exe の作り方(Windows)

[electron-builder](https://www.electron.build/) を使います。設定は `package.json` の `build` に入っています。

```bash
npm install
npm run dist
```

完成したファイルは `dist` フォルダに出力されます。

| ファイル | 内容 |
| --- | --- |
| `RailwayMapEditor Setup x.x.x.exe` | インストーラー版 |
| `RailwayMapEditor x.x.x.exe` | ポータブル版(インストール不要) |
| `Uninstall RailwayMapEditor.exe` | アンインストーラー(setupと同じ `dist` フォルダに出ます) |

どちらか一方だけ作りたい場合は、`package.json` の `"target": ["nsis", "portable"]` を編集してください(`nsis` がインストーラー版、`portable` がポータブル版です)。

### アンインストーラーについて

`npm run dist` はインストーラーを作ったあと、`dist/Uninstall RailwayMapEditor.exe` も自動で生成します。アンインストーラーだけ作り直したいときは次を実行します。

```bash
npm run uninstaller
```

- NSIS のアンインストーラーはビルドだけでは作れず、「インストーラーを一度動かす」ことで書き出されます。このリポジトリの `build/uninstaller.nsi` はそのための小さな生成用インストーラーで、`scripts/make-uninstaller.js` がその一連(コンパイル → 書き出し → `dist` へコピー → 一時ファイル削除)を自動化しています。`makensis` は electron-builder が入れたものを使います
- インストール先は、実行時にレジストリと既定のフォルダを調べて特定するため、別のPCでも動きます
- 実行すると確認ダイアログが出て、「起動中のアプリの終了 → ショートカット削除 → 本体フォルダの削除 → レジストリ(設定→アプリの一覧)の削除」の順に処理します
- 作成した路線図データ(`%APPDATA%\railway-map-editor`)は、**別途確認ダイアログで「はい」を選んだ場合のみ**削除します。「いいえ」なら残るので、あとで入れ直してもそのまま使えます
- `/S` を付けてサイレント実行もできます(この場合はデータは常に残ります)
- Windowsの「設定 → アプリ」からもアンインストールできます(インストーラーが元から登録しているアンインストーラーが使われます)
- アンインストーラー自体の削除処理は、誤って消して困る備えとして「ドライラン」(`RME_DRYRUN` 環境変数に書き出し先ファイルを指定)で検証できます。指定するとインストール先を特定して書き出すだけで終了します

### 配布するときの注意

- Windows上でビルドするのが確実です。Mac / LinuxからWindows用exeを作るには、追加の準備が必要です
- コード署名をしていないため、初回起動時にWindowsの「SmartScreen」が警告を出すことがあります。「詳細情報」から「実行」を選ぶと起動できます
- データは、使う人のPC内(ユーザーデータフォルダ)に保存されます。配布したexeは、受け取った人の環境では空の状態から始まります。路線図を共有したいときは「書き出し」で作ったJSONを渡し、相手に「読み込み」をしてもらってください

## データの保存場所とバックアップ

編集内容は、アプリのユーザーデータ領域(ブラウザのlocalStorage相当)に自動保存されます。
PCの入れ替えやアプリの削除に備えて、大切な路線図は「書き出し」でJSONファイルとして保存しておくことをおすすめします。

## 現在の制限

- 路線の分岐や、直線以外(曲線)の表現には対応していません(幹線道路も折れ線のみです)
- キャンバスは自動で広がりますが、原点は左上固定で右・下方向にのみ拡張されます
- 旧データ(道路を路線として保存していた形式)は、自動的に「独立した道路 + バス停」へ変換されます
- 同じ路線図を複数のウィンドウで同時に編集すると、あとから操作した側の変更が残ります

## ファイル構成

```

├── main.js        # Electronのメインプロセス(ウィンドウ管理・Ctrl+Wの処理)
├── index.html     # 画面の構造とスタイル(HTML / CSS)
├── renderer.js    # 編集ロジック(画面側のJavaScript)
├── build/
│   └── uninstaller.nsi       # アンインストーラーのNSISスクリプト
└── scripts/
    └── make-uninstaller.js   # dist にアンインストーラーを同梱する処理
```
